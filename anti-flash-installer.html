Anti-Flash 0.1.0

A reversible dark-mode bookmarklet. This page works offline and makes no network requests.

Install

  1. Show the bookmarks bar (Ctrl+Shift+B, or Cmd+Shift+B on macOS).
  2. Drag this button onto the bookmarks bar: Anti-Flash
  3. Open the page you want to darken and click the bookmark. Click it again to turn Anti-Flash off or on. Use Remove in the floating panel to take it off the page completely.
  4. Optional: press Analyze in the panel to adapt the page's own colors (Auto). Manual goes back.

You can also click the button above to try it on this page.

If dragging does not work

Create a new bookmark, name it Anti-Flash, and paste the text below as its URL. Some managed browsers block bookmarklets however you create them; Anti-Flash does not try to get around that.

DevTools alternative

Where your browser policy allows DevTools, paste the contents of anti-flash.js into a DevTools snippet and run it on the page.
